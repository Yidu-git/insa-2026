# WebSockets
## What is a WebSocket ?

**WebSocket** is a protocol used when the browser wants to create a persistent connection to a server. WebSockets are most commonly used in scenarios where data is updated live or in real-time.

Before WebSockets, browsers repeatedly sent an HTTP request to a server to view live data. This process is usually called polling. Polling is too slow and inefficient to retrieve data like live-streams and competitions.
